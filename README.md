Descripción

Portafolio profesional desarrollado para centralizar mi experiencia, formación, habilidades técnicas y proyectos de desarrollo de software.

El sitio fue construido con React y Vite, utilizando componentes reutilizables y un diseño adaptable a diferentes dispositivos.

Pasos
Clona el repositorio:
git clone https://github.com/Evegr12/Portafolio-EvelinGarcia.git
Entra a la carpeta:
cd Portafolio-EvelinGarcia
Instala las dependencias:
npm install
Ejecuta el servidor de desarrollo:
npm run dev
Abre la dirección mostrada en la terminal.
Comandos
Desarrollo
npm run dev
Construcción para producción
npm run build
Vista previa de producción
npm run preview
