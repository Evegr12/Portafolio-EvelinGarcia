## Descripción

Portafolio profesional desarrollado para centralizar mi experiencia, formación, habilidades técnicas y proyectos de desarrollo de software.

El sitio fue construido con React y Vite, utilizando componentes reutilizables y un diseño responsivo que se adapta a computadoras, tabletas y dispositivos móviles.

## Instalación

### Requisitos

- Node.js.
- npm.
- Git.

### Pasos

1. Clona el repositorio:

```bash
git clone https://github.com/Evegr12/Portafolio-EvelinGarcia.git
```

2. Entra a la carpeta del proyecto:

```bash
cd Portafolio-EvelinGarcia
```

3. Instala las dependencias:

```bash
npm install
```

4. Ejecuta el servidor de desarrollo:

```bash
npm run dev
```

5. Abre en el navegador la dirección mostrada en la terminal.
