# Portafolio de Evelin García Romero

Portafolio profesional desarrollado con React y Vite para presentar proyectos, habilidades y experiencia como desarrolladora Java Full Stack.

## Tecnologías

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Construir para producción

```bash
npm run build
```
