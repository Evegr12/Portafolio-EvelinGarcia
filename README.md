## Descripción

Portafolio profesional desarrollado para centralizar mi experiencia, formación, habilidades técnicas y proyectos de desarrollo de software.

El sitio fue construido con React y Vite, utilizando componentes reutilizables y un diseño responsivo que se adapta a computadoras, tabletas y dispositivos móviles.

## Estructura del proyecto

```text
Portafolio-EvelinGarcia/
├── public/
│   └── archivos públicos
├── src/
│   ├── assets/
│   │   └── imágenes y recursos visuales
│   ├── components/
│   │   └── componentes reutilizables
│   ├── data/
│   │   └── información de proyectos y contenido
│   ├── App.jsx
│   └── main.jsx
├── index.html
├── package.json
├── vite.config.js
└── README.md
```

| Archivo o carpeta | Descripción                                                 |
| ----------------- | ----------------------------------------------------------- |
| `src/assets/`     | Contiene imágenes, iconos y recursos visuales.              |
| `src/components/` | Contiene los componentes reutilizables del portafolio.      |
| `src/data/`       | Almacena la información utilizada en proyectos y secciones. |
| `App.jsx`         | Organiza los componentes principales de la aplicación.      |
| `main.jsx`        | Inicializa la aplicación de React.                          |
| `index.html`      | Documento principal de la aplicación.                       |
| `package.json`    | Contiene las dependencias y comandos del proyecto.          |
| `vite.config.js`  | Contiene la configuración de Vite.                          |

## Instalación

### Requisitos

* Node.js.
* npm.
* Git.

### Pasos

1. Clona el repositorio:

```bash
git clone https://github.com/Evegr12/Portafolio-EvelinGarcia.git
```

2. Entra a la carpeta del proyecto:

```bash
cd Portafolio-EvelinGarcia
```

3. Instala las dependencias:

```bash
npm install
```

4. Ejecuta el servidor de desarrollo:

```bash
npm run dev
```

5. Abre en el navegador la dirección mostrada en la terminal.
